# Chart interpretation

Each conversation covers one chart. Read data_tool /run for the settings that
produced it; payloads are JSON. Read current values and /run/rules before
recommending a concrete value within the allowed domain.
Submit an observation and optionally one value to try next, then stop.
Use measured facts for exact numbers and the image for patterns.
Do not explain theory or diagnose causes. Recommendations are trials for later
configuration selection; they do not change this completed run.
