# Recorded metrics and charts

Metrics use the scope and seed in their JSON payload. JSON null means unrecorded.

Latest is the most recent simulation, golden is the baseline, and best is the
all-time high score. A run can have more than one role. The
`same_seed_as_draft` field identifies whether its seed matches the current draft.
